# Conventional Commits 1.0.0 (summary)
Format: `<type>[optional scope]: <description>`, optional body, optional footers.
Types: feat (new feature), fix (bug fix), docs, style, refactor, perf, test, build, ci, chore.
Breaking change: `!` after the type/scope, or a `BREAKING CHANGE:` footer.
Scope: a noun for the section of the codebase, in parentheses, e.g. `feat(parser):`.
